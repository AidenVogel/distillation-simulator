# distillation-simulator

Python simulation of ethanol-water distillation using the McCabe-Thiele method.

## Goal
Build a tool that shows how many stages a distillation column needs to reach 
a desired ethanol purity, and how the reflux ratio changes that answer.

## Status
Work in progress. Just getting started.
